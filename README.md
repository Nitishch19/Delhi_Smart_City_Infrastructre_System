# Delhi_Smart_City_Infrastructre_System

app link : https://delhismartcityinfrastructresystemdashboard.streamlit.app/

Built an AI-driven Smart City Infrastructure System that analyzes how road surface conditions impact urban traffic flow and mobility. The project combines computer vision, geospatial mapping, real-time weather data, and predictive analytics to monitor infrastructure health, optimize routing, and support smarter municipal decision-making.


Key Features :
AI-powered road damage detection using YOLO concepts trained on the RDD-2022 dataset.
Interactive dashboard built with Streamlit for real-time visualization and route analysis.
Integration with OSRM API for route optimization and OpenWeatherMap API for weather-aware traffic analysis.
Dynamic rerouting based on road hazards, congestion, and environmental conditions.
Municipal cost estimation and analytics dashboard with heatmaps, radar charts, and regression visualizations.
Digital Twin simulation using synthetic hazard datasets to model real-world road conditions.

Tech Stack :
Python • Streamlit • YOLO • OpenCV • Pandas • Folium • OSRM API • OpenWeatherMap API • Computer Vision • Geospatial Analytics • Machine Learning
